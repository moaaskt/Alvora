# Plan 06-04: Roteador OpenRouter com Fallback, Gerador de Cursos e Insights Executivos

## Objective
Implementar o serviço de IA resiliente `OpenRouterResilientService` com chaveamento de fallback em cascata (`deepseek-r1` -> `llama-3.3-70b` -> `qwen3`), o gerador interativo de grade curricular via IA (`CurriculumAiGenerator`) para instrutores e o painel de diagnósticos e insights executivos de ROI (`AiExecutiveInsights`) para gestores de RH e admin Alvora.

## User Story
**As a** instrutor ou gestor corporativo,
**I want to** gerar estruturas completas de novos cursos por comando em linguagem natural e visualizar diagnósticos executivos sobre a retenção do time com garantia de alta disponibilidade através de fallback entre modelos de IA,
**so that** nossa produção de conteúdo seja acelerada e tenhamos inteligência estratégica sobre o ROI dos treinamentos.

<task id="06-04-01" type="tracer">
  <name>Serviço de Fallback OpenRouterResilientService</name>
  <action>
    Atualizar `config/ai.php` com configurações do OpenRouter:
    - `api_key`, `base_url` (`https://openrouter.ai/api/v1`), lista ordenada de modelos:
      1. `deepseek/deepseek-r1:free`
      2. `meta-llama/llama-3.3-70b-instruct:free`
      3. `qwen/qwen3-235b-a22b:free`
    Criar `App\Services\OpenRouterResilientService`:
    - Método `complete(string $prompt, array $options = []): array`:
      - Percorre a lista de modelos em cascata.
      - Para cada modelo, dispara requisição HTTP POST para `/chat/completions` com timeout de 8s.
      - Se a requisição for bem-sucedida, retorna `['content' => $text, 'model_used' => $model, 'attempts' => $count]`.
      - Se houver falha (4xx, 5xx, timeout), loga aviso (`Log::warning("OpenRouter fallback: $model failed, trying next...")`) e tenta o modelo seguinte.
      - Se todos falharem ou se mock estiver ativado, retorna resposta padrão resiliente de contingência.
    - Método `generateStructuredCurriculum(string $topic, string $targetAudience): array`:
      - Força prompt com instrução de retorno estritamente em JSON com chaves: `title`, `description`, `modules` (com `title` e `lessons` contendo `title`, `description`, `duration_minutes`).
  </action>
  <verify>
    <automated>test -f app/Services/OpenRouterResilientService.php</automated>
    <fails_when>non-zero exit</fails_when>
  </verify>
</task>
