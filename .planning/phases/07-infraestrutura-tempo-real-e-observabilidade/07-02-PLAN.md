# Plan 07-02: Health Check API, Orquestração Docker com Octane e Observabilidade

## Objective
Implementar o serviço de diagnóstico e endpoint de saúde operacional `/api/health` avaliando banco de dados, cache/redis e storage, construir o `Dockerfile` otimizado para Laravel Octane e o `docker-compose.yml` integrando todos os serviços (app, mysql, redis, horizon, reverb) e configurar a instrumentação de observabilidade para desenvolvimento (Telescope) e produção (Sentry).

## User Story
**As a** operador de infraestrutura (DevOps) ou engenheiro do sistema,
**I want to** monitorar o status integral da aplicação através de um health check automatizado e contar com containers Docker prontos para alta performance com Laravel Octane,
**so that** a plataforma Alvora opere com 99.9% de disponibilidade e diagnóstico instantâneo de anomalias.

<task id="07-02-01" type="tracer">
  <name>Serviço HealthCheckService e Endpoint /api/health</name>
  <action>
    Desenvolver `App\Services\HealthCheckService`:
    - Método `check(): array`:
      1. Database: executa query simples (`SELECT 1`), mede latência em ms e captura eventuais erros.
      2. Cache / Redis: grava e recupera chave temporária (`health_check_ping`), medindo tempo de resposta.
      3. Storage: escreve e deleta arquivo temporário (`health_storage_check.txt`).
      4. Sistema: reporta consumo de memória (`memory_usage_mb`) e versão do PHP/Laravel.
      - Determina status global: `ok` (todos saudáveis), `degraded` (apenas cache/storage com lentidão) ou `error` (falha no banco de dados).
    Desenvolver `App\Http\Controllers\Api\HealthCheckController`:
    - Endpoint público `GET /api/health`: retorna JSON estruturado com status HTTP 200 (se `ok` ou `degraded`) ou 503 (se `error`).
    Registrar rota em `routes/api.php`.
  </action>
  <verify>
    <automated>test -f app/Services/HealthCheckService.php &amp;&amp; test -f app/Http/Controllers/Api/HealthCheckController.php</automated>
    <fails_when>non-zero exit</fails_when>
  </verify>
</task>

  <action>

<task id="07-02-03">
  <name>Orquestração Completa com docker-compose.yml</name>
  <action>
    Criar `docker-compose.yml` para orquestração de microsserviços do monólito:
    1. `app`: Container da aplicação servida via Laravel Octane na porta 8000.
    2. `mysql`: Banco relacional MySQL 8.0 na porta 3306 com volume persistente.
    3. `redis`: Instância Redis 7 Alpine na porta 6379 para cache, filas e websockets.
    4. `horizon`: Container dedicado rodando `php artisan horizon` para processamento contínuo das filas Redis.
    5. `reverb`: Container dedicado rodando `php artisan reverb:start --host=0.0.0.0 --port=8080` para WebSockets em tempo real.
    - Configurar redes internas (`alvora-network`), volumes e variáveis de ambiente padronizadas.
